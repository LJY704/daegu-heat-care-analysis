# 대구 HEAT-Care | 재현 가능한 분석 자료

## 목적
취업 포트폴리오에서 데이터 분석·관리 과정을 검증할 수 있도록 정리한 보조 자료입니다. `analyze.py`는 프로젝트의 분석 결과를 재현하기 위해 사후 정리한 코드입니다.

## 파일
- `source_2025_districts.csv`: 이전 분석 엑셀 `대구_2025_공원면적_정정_취약성_Kmeans_재계산.xlsx`의 `2025_구군별_재계산` 시트에서 총인구, 65세 이상 인구, 조성 공원면적 9개 행을 추출. 값은 소수점 반올림된 지표가 아니라 원자료 집계 열을 사용.
- `analyze.py`: 데이터 검증, 파생변수 생성, 표준화, 예비 지수, K=2/3 K-means, 실루엣 점수 비교, 결과 CSV 저장.
- `requirements.txt`: 재현에 필요한 라이브러리.
- `recomputed_results.csv`: 실행 후 생성되는 결과 파일.

## 실행
```bash
pip install -r requirements.txt
python analyze.py
```

## 지표와 해석
- 고령인구 비율 = 65세 이상 인구 / 총인구 × 100
- 1인당 공원면적 = 조성 공원면적 / 총인구
- 예비 취약성 지수 = [Z(고령인구 비율) − Z(1인당 공원면적)] / 2
- 표준화: `StandardScaler` (모집단 표준편차 사용)
- K-means: `random_state=42`, `n_init=50`; 군집 번호는 의미 없는 임의 식별자
- 9개 지역의 **탐색적 상대 비교**이며 실제 온열질환 위험, 그늘 접근성, 구·군별 기온을 측정하거나 예측한 지수가 아닙니다.

## 데이터 출처

- 행정안전부 연령별 주민등록인구: https://jumin.mois.go.kr/ageStatMonth.do
- 대구광역시 공원·유원지·녹지 현황: https://www.data.go.kr/data/15074086/fileData.do
- 통계청 SGIS 행정구역 경계: https://sgis.mods.go.kr/view/pss/downloadList (지도 시각화에 사용; 이 재현 스크립트는 지도 생성 기능을 포함하지 않음)

## 데이터 품질 주의
중구 공원면적 481,558㎡는 유형별 면적을 합산한 값입니다. 구·군별 합산과 원자료 전체 합계 사이 239,553㎡ 차이가 남아 있으며, 제공기관에서 그 원인을 공식 확인한 것은 아닙니다. 데이터는 독립적인 검증을 마친 공식 정정치가 아니라 **분석에 사용한 근거 있는 재구성값**입니다. 원본 자료와 해당 연도 기준일을 함께 재확인하세요.
